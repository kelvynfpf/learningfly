Como instalar e testar

  1. Windows

    No MySQL Installer, escolha Developer Default, mantenha a porta 3306 e cadastre a senha do root.

  2. Linux (Ubuntu/Debian)

    Instale, ligue o serviço e rode o assistente de segurança.

    sudo apt install mysql-server
sudo systemctl enable --now mysql
sudo mysql_secure_installation

  3. Testar no Linux

    No Ubuntu, o root entra pelo sistema logo depois da instalação. Use sudo para a primeira conexão.

    sudo mysql
SHOW DATABASES;

  4. Testar no Windows

    Conecte com a senha que você definiu.

    mysql -u root -p
SHOW DATABASES;

Atenção. No Ubuntu, o comando mysql -u root -p logo depois de instalar costuma falhar. Isso acontece porque o root usa autenticação do sistema, e não senha.
