QA / Testes de Software

Encontrar problemas antes que o usuário encontre.

O que é Vídeo Primeiros passos Aulas Cursos

O que é

QA (garantia de qualidade) é a área que testa o software para achar defeitos e reduzir o risco de algo dar errado em produção.

Quem trabalha com QA planeja testes, executa à mão, registra os bugs com clareza e, com o tempo, automatiza os testes repetitivos com código.

Combina com quem é curioso, detalhista e gosta de perguntar "e se...?".

No dia a dia

  • Ler a história do backlog e escrever casos de teste.
  • Testar telas e APIs à mão, buscando o que pode quebrar.
  • Registrar bugs com passos para reproduzir, resultado esperado e obtido.
  • Automatizar testes que se repetem a cada versão.

Entenda em poucos minutos

Many - QA | Migração para TI, cerca de 4 min. Abrir no YouTube

Primeiros passos

Faça na ordem. Cada etapa termina com algo feito por você.

  1. Fundamentos de teste

    Assista às aulas de CTFL em português junto com o syllabus. Entenda tipos e níveis de teste.

    Atenção: O vocabulário do CTFL é o que as empresas usam nas vagas.

    • Curso de Testes de Software para iniciantes (CTFL) Curso, em português
    • Syllabus CTFL 4.0 em português Curso, em português

  2. Teste manual de verdade

    Escolha um site e escreva dez casos de teste para o cadastro. Execute e registre os bugs que achar.

    Atenção: Um bom relato de bug tem passos, resultado esperado, resultado obtido e print.

    • Curso completo de QA: do manual à automação Curso, em português

  3. Teste de API

    Instale o Postman e teste uma API pública: status, campos obrigatórios e mensagens de erro.

    Atenção: Teste também o caminho errado: dado vazio, formato inválido, sem permissão.

    • Postman Ferramenta

  4. Lógica e uma linguagem

    Para automatizar, aprenda o básico de JavaScript ou Python.

    Atenção: Não precisa ser dev, mas precisa ler e escrever código simples.

    • JavaScript (Curso em Vídeo) Curso, em português

  5. Primeira automação

    Automatize o login de um site de testes com Cypress ou Playwright e coloque no GitHub.

    Atenção: Automatize o que é repetitivo e estável, não tudo.

    • Cypress: seu primeiro teste Curso
    • Playwright: instalação e primeiros testes Curso

Evite no começo

  • Pular direto para automação sem saber testar à mão.
  • Registrar bug sem passos para reproduzir.
  • Testar só o caminho feliz.

Meta para o primeiro mês

Em 30 dias: um documento com dez casos de teste e três bugs bem relatados de um site real.
