UI Design

Aula 2 de 3, 8 min

Cor, contraste e tipografia

Regras simples para uma tela legível: contraste mínimo, poucas fontes e uma escala de tamanhos.

Contraste é acessibilidade

Texto precisa contrastar com o fundo para ser lido por todos, inclusive quem enxerga pouco ou usa o celular no sol. As diretrizes WCAG pedem contraste de pelo menos 4,5:1 para texto normal e 3:1 para texto grande (nível AA).

Cor com função

  • Escolha uma cor principal para ações e uma neutra para o resto.
  • Reserve vermelho para erro e verde para sucesso, como as pessoas esperam.
  • Nunca use só a cor para passar informação: junte um ícone ou texto, pensando em quem não distingue cores.

Tipografia

  • Use uma ou duas famílias de fonte, no máximo.
  • Crie uma escala: por exemplo, 16 px para texto, 20 para subtítulo, 25 para título.
  • Linhas muito longas cansam. Algo entre 45 e 75 caracteres por linha é confortável.
  • Para texto de leitura no celular, comece em 16 px.

Exercício

Pegue uma tela sua (ou de um site) e confira o contraste do texto principal com um verificador de contraste gratuito. Se estiver abaixo de 4,5:1, ajuste a cor e compare as duas versões.

Teste rápido

Escolha uma resposta em cada pergunta. A correção aparece na hora.

1. Qual o contraste mínimo do WCAG (nível AA) para texto normal?

4,5:1 para texto normal; 3:1 para texto grande.

2. Um formulário marca erros só deixando o campo vermelho. Qual o problema?

Informação não pode depender só da cor.

3. Quantas famílias de fonte é bom usar numa interface?

Poucas fontes deixam a interface consistente.
