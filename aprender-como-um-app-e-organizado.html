Como um app é organizado

Telas, componentes, estado e navegação: as quatro ideias que aparecem em todo app.

Telas e componentes

Um app é um conjunto de telas. Cada tela é montada com componentes menores: um botão, um campo de texto, um item de lista. No Flutter eles se chamam widgets; no Android com Compose, composables.

Estado

Estado é a informação que pode mudar enquanto o app está aberto: o texto digitado, os itens da lista, se a pessoa está logada. Quando o estado muda, a tela se redesenha para mostrar o novo valor.

Navegação

  • Pilha: uma tela abre por cima da outra e o botão voltar retorna.
  • Abas: telas principais lado a lado, na barra inferior.
  • Passe só o necessário de uma tela para a outra, como o id de um item.

De onde vêm os dados

Dados locais ficam no próprio celular. Dados compartilhados vêm de uma API ou de serviços como Firebase e Supabase. Sempre trate o caso de estar sem internet.

Exercício

Desenhe no papel um app de lista de compras: quais telas ele tem, como se navega entre elas e quais informações são estado.

3. O app busca dados de uma API e a internet cai. O que deve acontecer?
