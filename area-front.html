Front-end

Construir a parte do site que a pessoa vê e usa.

O que é Vídeo Primeiros passos Aulas Cursos

O que é

Front-end é o código que roda no navegador. Ele transforma o desenho das telas em páginas que funcionam em celular e computador.

A base são três linguagens: HTML organiza o conteúdo, CSS cuida da aparência e JavaScript faz a página reagir a cliques e mudar sozinha.

Combina com quem gosta de ver o resultado na hora e se importa com detalhes visuais.

No dia a dia

  • Transformar telas do Figma em HTML e CSS.
  • Programar comportamentos com JavaScript, como menus e formulários.
  • Buscar dados do back-end e mostrar na tela.
  • Testar o site em celulares e navegadores diferentes.

Entenda em poucos minutos

Tautorn Tech, cerca de 6 min. Abrir no YouTube

Primeiros passos

Faça na ordem. Cada etapa termina com algo feito por você.

  1. HTML e CSS

    Faça o módulo 1 do Curso em Vídeo ou as aulas do professor Rodrigo. Monte uma página sobre você.

    Atenção: Use as tags certas (título, lista, botão). Isso ajuda a acessibilidade e o Google.

    • HTML5 e CSS3: módulo 1 (Curso em Vídeo) Curso, em português
    • TDS: Linguagem de Marcação (Programação Visual para Web) Curso, em português

  2. Layout que funciona no celular

    Treine Flexbox e Grid com os jogos e deixe sua página boa numa tela pequena.

    Atenção: Comece desenhando para o celular e depois amplie para o computador.

    • Flexbox Froggy Curso
    • Grid Garden Curso

  3. JavaScript

    Aprenda variáveis, condições, funções e eventos. Faça uma lista de tarefas que adiciona e remove itens.

    Atenção: Entenda a lógica antes de pular para frameworks como React.

    • JavaScript (Curso em Vídeo) Curso, em português
    • Crie um site simples usando HTML, CSS e JavaScript Curso, em português

  4. Git e GitHub

    Coloque seus projetos no GitHub e publique um deles com o GitHub Pages.

    Atenção: Faça commits pequenos e com mensagens claras.

    • Git e GitHub (Curso em Vídeo) Curso, em português

  5. Três projetos no portfólio

    Uma página pessoal, uma landing page a partir de um layout pronto e um app simples com JavaScript.

    Atenção: Projeto terminado e publicado vale mais que dez pela metade.

    • Aprendendo desenvolvimento web Curso, em português

Evite no começo

  • Começar por um framework sem saber HTML, CSS e JavaScript.
  • Copiar código de tutorial sem entender cada linha.
  • Testar só no seu computador.

Meta para o primeiro mês

Em 30 dias: uma página pessoal publicada no GitHub Pages, funcionando bem no celular.
