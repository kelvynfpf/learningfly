Front-end

Aula 1 de 3, 8 min

Sua primeira página em HTML

Escreva uma página de verdade e entenda cada parte dela.

O que é HTML

HTML é a linguagem que organiza o conteúdo da página: títulos, parágrafos, listas, imagens e links. Cada parte fica dentro de uma tag, como <h1> para título principal.

Uma página completa

<!doctype html>
<html lang="pt-br">
<head>
  <meta charset="utf-8">
  <title>Sobre mim</title>
</head>
<body>
  <h1>Olá, eu sou a Ana</h1>
  <p>Estou aprendendo front-end.</p>
  <h2>O que já sei</h2>
  <ul>
    <li>HTML</li>
    <li>Um pouco de CSS</li>
  </ul>
  <a href="https://github.com">Meu GitHub</a>
</body>
</html>

Partes importantes

  • lang="pt-br": avisa o idioma para leitores de tela e buscadores.
  • <head>: informações sobre a página, que não aparecem no corpo.
  • <body>: o que aparece na tela.
  • Use a tag pelo significado: <h1> para o título, não para deixar a letra grande.

Exercício

Crie um arquivo index.html com seu nome, um parágrafo sobre você, uma lista do que quer aprender e um link. Abra no navegador.

Teste rápido

Escolha uma resposta em cada pergunta. A correção aparece na hora.

1. Qual tag é usada para o título principal da página?

<h1> é o título principal do conteúdo; <title> aparece na aba do navegador.

2. Para que serve o atributo lang="pt-br"?

Ajuda leitores de tela a pronunciar certo e buscadores a entender o idioma.

3. O que vai dentro de <body>?

O corpo da página é o conteúdo visível.
