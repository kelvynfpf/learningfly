O que é Vídeo Primeiros passos Aulas Cursos

O que é

Back-end é o código que roda no servidor. Ele recebe os pedidos que vêm do site ou do app, consulta o banco de dados e devolve a resposta.

É o back-end que cuida de login, regras do negócio, cadastro, pagamentos e envio de e-mails. Linguagens comuns: Python, JavaScript (Node.js), Java, PHP e C#.

Combina com quem gosta de lógica, de resolver problemas e de entender como as coisas funcionam por dentro.

No dia a dia

  • Criar APIs que o front-end e os apps usam.
  • Modelar tabelas e escrever consultas no banco de dados.
  • Cuidar de segurança: quem pode ver e mudar cada dado.
  • Investigar erros em produção a partir de logs.

Primeiros passos

Faça na ordem. Cada etapa termina com algo feito por você.

  1. Lógica de programação

    Faça o curso de algoritmos e resolva exercícios pequenos todos os dias.

    Atenção: Lógica é a base de tudo. Não pule esta etapa.

    • Algoritmos e Lógica de Programação (Curso em Vídeo) Curso, em português

  2. Uma linguagem só

    Escolha Python e vá até funções e listas. Termine um mundo inteiro antes de olhar outra linguagem.

    Atenção: Trocar de linguagem toda semana atrasa. Os conceitos servem para todas.

    • Python 3: Mundo 1 (Curso em Vídeo) Curso, em português
    • Linguagem de Programação Python: Básico Curso, em português

  3. Banco de dados e SQL

    Aprenda SELECT, INSERT, UPDATE e JOIN. Crie as tabelas de uma biblioteca ou loja.

    Atenção: Pense em como os dados se relacionam antes de criar as tabelas.

    • Curso de MySQL (Curso em Vídeo) Curso, em português
    • SQLBolt Curso

  4. Git e terminal

    Use Git em todos os projetos a partir daqui e aprenda os comandos básicos do terminal.

    Atenção: Nunca suba senhas ou chaves para o GitHub.

    • Git e GitHub (Curso em Vídeo) Curso, em português
    • Pro Git Curso, em português

  5. Sua primeira aplicação web

    Faça o tutorial Django Girls e monte um blog com login e banco de dados.

    Atenção: Entenda o caminho do pedido: navegador, servidor, banco, resposta.

    • Tutorial Django Girls Curso, em português
    • Programação server-side: primeiros passos Curso

Evite no começo

  • Estudar três linguagens ao mesmo tempo.
  • Ignorar SQL: quase todo sistema tem banco de dados.
  • Guardar senhas no código.

Meta para o primeiro mês

Em 30 dias: um programa em Python que lê e grava dados num arquivo ou banco, versionado no GitHub.
