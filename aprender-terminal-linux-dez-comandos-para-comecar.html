Infraestrutura + DBA

Aula 2 de 3, 8 min

Terminal Linux: dez comandos para começar

Os comandos que você vai usar todos os dias num servidor.

Os comandos

pwd                 # mostra em que pasta você está
ls -l               # lista arquivos com detalhes
cd /var/log         # entra numa pasta
mkdir projetos      # cria uma pasta
cp a.txt b.txt      # copia um arquivo
mv b.txt backup/    # move ou renomeia
rm arquivo.txt      # apaga (sem lixeira!)
cat arquivo.txt     # mostra o conteúdo
sudo apt update     # atualiza a lista de pacotes (Ubuntu/Debian)
man ls              # abre o manual de um comando

Cuidados

  • rm apaga de vez. Confira duas vezes antes, principalmente com sudo.
  • sudo executa como administrador. Use só quando precisar.
  • Tab completa nomes de arquivos e pastas: economiza tempo e evita erro de digitação.
  • Treine numa máquina virtual, não no servidor de produção.

Exercício

Numa máquina virtual Ubuntu, crie a pasta estudos, dentro dela um arquivo notas.txt com três linhas (use nano notas.txt), copie para notas-backup.txt e liste a pasta com ls -l.

Teste rápido

Escolha uma resposta em cada pergunta. A correção aparece na hora.

1. Qual comando mostra a pasta atual?

pwd significa print working directory.

2. O que acontece com um arquivo apagado com rm?

No terminal, rm não usa lixeira.

3. Para que serve o sudo?

Dá permissão elevada para o comando.
