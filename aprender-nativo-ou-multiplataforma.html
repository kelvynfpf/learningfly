Aula 1 de 3, 6 min

Nativo ou multiplataforma?

As três formas mais comuns de fazer um app e como escolher a sua para estudar.

Os caminhos

CaminhoLinguagemFunciona em
Android nativoKotlinAndroid
iOS nativoSwiftiPhone (exige Mac para desenvolver)
FlutterDartAndroid, iPhone, web e desktop
React NativeJavaScript / TypeScriptAndroid e iPhone

Como escolher para estudar

  • Já sabe JavaScript? React Native aproveita esse conhecimento.
  • Quer começar do zero com um caminho só? Flutter tem documentação muito completa.
  • Quer trabalhar especificamente com Android? Kotlin com Android Studio.
  • Olhe as vagas da sua cidade: elas mostram o que as empresas pedem.

O que é igual em todos

Telas, navegação, estado, chamadas a APIs e publicação na loja existem em qualquer caminho. Aprender bem um deles torna os outros muito mais fáceis.

Exercício

Pesquise dez vagas de desenvolvimento mobile na sua região. Conte quantas pedem Kotlin, Flutter, React Native e Swift. Escolha seu caminho com base nisso.

Teste rápido

Escolha uma resposta em cada pergunta. A correção aparece na hora.

1. Qual linguagem é usada no Flutter?

Flutter usa Dart.

2. Para desenvolver apps nativos de iPhone com Swift, você precisa de...

O Xcode, usado para iOS, só roda em macOS.

3. Quem já sabe JavaScript tende a se adaptar melhor a...

React Native usa JavaScript ou TypeScript.
