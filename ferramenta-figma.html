Como instalar e testar

  1. Começar

    Crie uma conta gratuita e escolha o plano Starter. Os rascunhos são ilimitados.

  2. Limites do plano gratuito

    Até 3 arquivos de Design, 3 de FigJam e 3 de Slides na pasta do plano. Outras pessoas só entram nos seus rascunhos para ver. Para editar juntas, o plano precisa ser pago. O Dev Mode não vem no Starter. Guia oficial (abre em outra aba)

  3. Atalhos para decorar primeiro

    Windows (no Mac, troque Ctrl por Command e Alt por Option):

    Shift + A            adicionar auto layout
Alt + Shift + A      remover auto layout
Ctrl + Alt + K       criar componente
Ctrl + Alt + B       desvincular instância

  4. Primeiro exercício

    Faça um botão com auto layout, transforme em componente e crie uma tela de login com ele. Depois ligue as telas em um protótipo.

Atenção. Se o limite de 3 arquivos apertar, apague os que já terminou ou exporte os projetos que quer guardar.
