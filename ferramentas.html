Ferramentas

23 ferramentas gratuitas, com passos para instalar e testar. Baixe sempre pelo site oficial.

Design e prototipação

  • Figma

    Cria telas, componentes e protótipos clicáveis no navegador, com várias pessoas no mesmo arquivo.

    Design de interfacesPlano Starter gratuito, com limites.

  • Adobe XD

    Programa da Adobe para telas e protótipos. Útil para entender projetos antigos feitos nele.

    Design de interfacesProduto da Adobe. Confira as condições no site.

Desenvolvimento mobile

  • Android Studio

    Ambiente oficial do Google para criar apps Android, com editor, emulador e ferramentas de teste.

    Ambiente para AndroidGratuito. É preciso aceitar o contrato de licença do Android SDK.

  • Flutter

    Cria apps para Android e iOS com a linguagem Dart e quase o mesmo código.

    Framework multiplataformaGratuito e de código aberto.

  • Expo (React Native)

    Cria apps para Android e iOS com JavaScript ou TypeScript e React. O Expo Go deixa testar no próprio celular.

    Framework multiplataformaGratuito. Conta Expo gratuita para testar em iPhone.

  • Postman

    Envia requisições HTTP e mostra a resposta, para testar uma API antes de ligar o app a ela.

    Teste de APIsPlano Free: US$ 0, para 1 pessoa.

  • Firebase

    Serviços do Google para login, banco de dados, arquivos e avisos do app, sem montar um servidor.

    Login, banco de dados e arquivosPlano Spark sem custo, com cotas.

  • Supabase

    Banco PostgreSQL na nuvem com login de usuários, arquivos e API pronta.

    Banco de dados PostgreSQL e loginPlano gratuito, com limites.

Infraestrutura e nuvem

  • Oracle VirtualBox

    Cria máquinas virtuais no seu computador para testar sistemas sem mexer no que já está instalado.

    Virtualização localGPLv3 (programa). O Extension Pack tem licença própria.

  • Docker

    Empacota uma aplicação com tudo o que ela precisa, para rodar igual em qualquer computador.

    ContêineresDocker Engine: Apache 2.0. Docker Desktop: gratuito para estudo e pequenas empresas.

  • Cisco Packet Tracer

    Simula roteadores, switches e computadores para praticar configuração de redes sem equipamento físico.

    Simulação de redesGratuito com conta da Cisco Networking Academy.

  • Wireshark

    Mostra os pacotes que passam pela sua placa de rede, para entender protocolos e achar problemas.

    Análise de tráfegoGPLv2.

  • PuTTY

    Conecta em servidores remotos pelo terminal, usando SSH.

    Acesso remoto (SSH)MIT.

  • Zabbix

    Acompanha servidores e serviços e avisa quando algo sai do normal.

    MonitoramentoAGPLv3.Em verificação

  • Terraform

    Descreve servidores e serviços de nuvem em arquivos de texto e cria tudo com um comando.

    Infraestrutura como códigoBUSL 1.1 (uso gratuito para estudo).

Banco de dados (DBA)

  • PostgreSQL

    Banco de dados relacional completo e muito usado em produção.

    Banco relacionalLicença PostgreSQL (livre).

  • MySQL Community Server

    Banco relacional muito usado em sites e aplicações web.

    Banco relacionalGPLv2.

  • MongoDB Community Server

    Banco que guarda documentos parecidos com JSON, em vez de tabelas.

    Banco NoSQLSSPL.

  • DBeaver Community

    Uma só tela para conectar em PostgreSQL, MySQL, SQLite, Oracle e SQL Server.

    Cliente SQL universalApache 2.0.

  • pgAdmin 4

    Interface oficial para administrar o PostgreSQL e rodar consultas.

    Interface do PostgreSQLLicença PostgreSQL (livre).

  • MySQL Workbench

    Administra o MySQL, roda consultas e gera tabelas a partir de diagramas.

    Interface do MySQLGPLv2.

  • brModelo

    Ferramenta acadêmica em português para desenhar o modelo conceitual (MER) e o modelo lógico.

    Modelagem conceitualGratuito. Confira a licença na página.Em verificação

  • dbdiagram.io

    Desenha o banco escrevendo texto (DBML) e gera o diagrama na hora, com exportação do script SQL.

    Modelagem onlinePlano gratuito com limites.
