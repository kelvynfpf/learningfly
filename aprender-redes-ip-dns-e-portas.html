Redes: IP, DNS e portas

Como um computador encontra outro na internet.

Endereço IP

Cada dispositivo numa rede tem um endereço IP, como 192.168.0.10 (IPv4). É como o endereço de uma casa: é para onde os dados são entregues.

DNS

Pessoas lembram nomes, computadores usam números. O DNS traduz um nome como www.gov.br para o IP do servidor. Quando o DNS falha, parece que "a internet caiu", mesmo com a conexão funcionando.

Portas

Num mesmo servidor rodam vários serviços. A porta diz com qual serviço você quer falar.

PortaServiço
22SSH (acesso remoto seguro)
80HTTP
443HTTPS
3306MySQL
5432PostgreSQL
27017MongoDB

Exercício

No terminal, rode ping www.gov.br e nslookup www.gov.br. Anote o IP que aparece. Depois descubra o IP do seu computador (ipconfig no Windows, ip a no Linux).

Teste rápido

Escolha uma resposta em cada pergunta. A correção aparece na hora.

1. O que o DNS faz?

Ele é a "lista telefônica" da internet.

2. Qual porta é usada pelo HTTPS?

HTTPS usa a porta 443 por padrão.

3. Para acessar um servidor Linux remotamente com segurança, usa-se...

SSH é o padrão de acesso remoto criptografado.
