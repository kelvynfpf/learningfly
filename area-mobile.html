Mobile

Criar aplicativos para celular.

O que é Vídeo Primeiros passos Aulas Cursos

O que é

Mobile é a área que desenvolve apps para Android e iPhone. Dá para fazer um app para cada sistema (nativo) ou um código só para os dois (multiplataforma).

No Android nativo, a linguagem principal é Kotlin, no Android Studio. Para multiplataforma, os mais usados são Flutter (linguagem Dart) e React Native (JavaScript).

Combina com quem gosta de criar coisas que cabem no bolso e quer ver o próprio app no celular.

No dia a dia

  • Montar as telas do app e a navegação entre elas.
  • Ligar o app a uma API ou a um serviço como o Firebase.
  • Testar no emulador e em celulares de verdade.
  • Publicar versões na Play Store e na App Store.

Entenda em poucos minutos

Sobrinho de TI, cerca de 8 min. Abrir no YouTube

Primeiros passos

Faça na ordem. Cada etapa termina com algo feito por você.

  1. Lógica e uma linguagem

    Antes do app, aprenda lógica de programação. Se for de Flutter, estude Dart; se for de Android, Kotlin; se for de React Native, JavaScript.

    Atenção: Escolha um caminho e fique nele por alguns meses.

    • Algoritmos e Lógica de Programação (Curso em Vídeo) Curso, em português
    • Tour pela linguagem Kotlin Curso

  2. Prepare o ambiente

    Instale o Android Studio e rode um app de exemplo no emulador.

    Atenção: O emulador pede computador com boa memória. Se estiver lento, use seu próprio celular com o modo desenvolvedor.

    • Android Studio Ferramenta
    • Flutter Ferramenta

  3. Seu primeiro app

    Siga um curso do começo ao fim e faça um app de uma tela que mostra uma lista.

    Atenção: Termine o curso escolhido antes de começar outro.

    • Curso de Flutter: criando seu primeiro app Curso, em português
    • Android Basics with Compose Curso

  4. Dados de verdade

    Faça o app buscar dados de uma API pública e salvar algo no Firebase ou Supabase.

    Atenção: Trate o caso sem internet: o app não pode travar.

    • Postman Ferramenta
    • Firebase Ferramenta

  5. Projetos para o portfólio

    Faça dois ou três apps pequenos e completos e coloque o código no GitHub com prints das telas.

    Atenção: Um app simples bem feito vale mais que um grande pela metade.

    • 5 projetos para praticar Mobile Guia
    • Por onde começar em Mobile Guia

Evite no começo

  • Estudar Flutter, React Native e Kotlin ao mesmo tempo.
  • Começar sem saber lógica de programação.
  • Testar só no emulador.

Meta para o primeiro mês

Em 30 dias: um app de lista rodando no seu celular, com o código no GitHub.
