Banco de dados: tabelas, chaves e backup

Como os dados se organizam num banco relacional e como protegê-los.

Tabelas e chaves

  • Tabela: conjunto de registros com as mesmas colunas, como clientes ou pedidos.
  • Chave primária: identifica cada linha de forma única, como o id do cliente.
  • Chave estrangeira: liga uma tabela a outra, como pedidos.cliente_id apontando para clientes.id.

Exemplo

CREATE TABLE clientes (
  id INT PRIMARY KEY AUTO_INCREMENT,
  nome VARCHAR(100) NOT NULL
);

CREATE TABLE pedidos (
  id INT PRIMARY KEY AUTO_INCREMENT,
  cliente_id INT NOT NULL,
  total DECIMAL(10,2),
  FOREIGN KEY (cliente_id) REFERENCES clientes(id)
);

Backup e restauração (MySQL)

# gerar o backup do banco loja
mysqldump -u root -p loja > loja.sql

# restaurar num banco vazio
mysql -u root -p loja_teste < loja.sql

Regra de ouro do DBA

Backup que nunca foi restaurado não é garantia. Teste a restauração com frequência e guarde cópias fora do servidor principal.

Exercício

No MySQL, crie as tabelas clientes e pedidos, insira três clientes e cinco pedidos, faça o backup com mysqldump e restaure num banco novo. Confira se os dados estão lá.

Teste rápido

Escolha uma resposta em cada pergunta. A correção aparece na hora.

1. O que é uma chave primária?

Ela garante que cada registro seja único.

2. A chave estrangeira serve para...

Ela garante que o pedido aponte para um cliente que existe.

3. Qual a forma de saber se um backup funciona?

Só a restauração prova que o backup serve.
