Primeiro app em Flutter: um contador

Leia linha a linha um app pequeno e veja estado e tela funcionando juntos.

O código

import 'package:flutter/material.dart';

void main() => runApp(const MaterialApp(home: Contador()));

class Contador extends StatefulWidget {
  const Contador({super.key});
  @override
  State<Contador> createState() => _ContadorState();
}

class _ContadorState extends State<Contador> {
  int total = 0;

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: const Text('Contador')),
      body: Center(child: Text('Você tocou $total vezes')),
      floatingActionButton: FloatingActionButton(
        onPressed: () => setState(() => total++),
        child: const Icon(Icons.add),
      ),
    );
  }
}

O que cada parte faz

  • main e runApp iniciam o app.
  • StatefulWidget é um componente que tem estado.
  • total é o estado: começa em 0.
  • build monta a tela: barra superior, texto no centro e um botão flutuante.
  • setState avisa o Flutter que o estado mudou, e a tela é redesenhada com o novo número.

Exercício

Rode este app (crie um projeto com flutter create e troque o conteúdo de lib/main.dart). Depois, adicione um segundo botão que diminui o número, sem deixar passar de zero.

Suas anotações

Escreva enquanto estuda. Uma ideia por linha. Termine a linha com “?” para marcar uma dúvida. Fica salvo só neste navegador.

Resumo da aula

Teste rápido

Escolha uma resposta em cada pergunta. A correção aparece na hora.

1. O que faz o setState?

Sem setState, a variável muda mas a tela não.

2. Onde a tela é montada?

build descreve o que aparece na tela.

3. Qual comando cria um projeto novo de Flutter?

flutter create nome_do_projeto.
