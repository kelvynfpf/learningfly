JavaScript: fazendo a página reagir

Responda a um clique e mude a tela sem recarregar.

O papel do JavaScript

HTML é o conteúdo, CSS é a aparência e JavaScript é o comportamento. Com ele, a página responde a cliques, valida formulários e busca dados.

Um contador

<p>Você clicou <span id="total">0</span> vezes.</p>
<button id="botao" type="button">Clique aqui</button>

<script>
  const botao = document.querySelector("#botao");
  const total = document.querySelector("#total");
  let cliques = 0;

  botao.addEventListener("click", () => {
    cliques = cliques + 1;
    total.textContent = cliques;
  });
</script>

Linha a linha

  • document.querySelector encontra um elemento na página.
  • let cria uma variável que pode mudar; const, uma que não muda.
  • addEventListener("click", ...) executa a função a cada clique.
  • textContent troca o texto do elemento.

Exercício

Mude o contador para ter também um botão "Zerar". Depois, faça o texto ficar em negrito quando passar de 10 cliques.

Teste rápido

Escolha uma resposta em cada pergunta. A correção aparece na hora.

1. Qual destas linguagens cuida do comportamento da página?

JavaScript faz a página reagir.

2. O que faz addEventListener("click", ...)?

Ele fica "ouvindo" o evento e chama a função.

3. Qual a diferença entre let e const?

Use const quando o valor não for reatribuído.
